# 职业研究来源表

共享层只保存来源入口、查询模板、可信度和访问限制。职业事实、薪资样本、报告与进度仍写在用户项目中。入口可能改版，使用前核验实际页面、地区、年份和口径。

## 使用顺序

1. 政府和公共就业服务，用于职业存在、分类、政策和宏观口径。
2. 企业官网与官方招聘页，用于具体岗位、雇主与技术栈。
3. 招聘平台职位，用于存在性和市场样本，不代表全市场统计。
4. 行业协会、研究机构和高校报告，用于行业结构与趋势。
5. 从业者一手经验，用于真实工作过程，不能单独代表整体。
6. 国际来源只用于补充，不直接替代中国大陆口径。

## 来源记录规则

每个来源至少记录：

- 来源类型、标题、发布机构和原始 URL。
- 发布日期、访问日期、覆盖地区和统计口径。
- 来源等级：`A`、`B`、`C`、`D`。
- 样本量：数量与范围；没有样本概念时写「不适用」。
- 支持的结论、可信度、限制和短摘录。
- 核验状态：`已核验`、`部分核验`、`待核验`、`已失效`。
- 替代链接。无替代时写「无」。

短摘录只保留判断所需的最小片段，不保存整站、整篇报告或大规模受版权保护内容。受限来源只留元数据和结论，不绕过登录、验证码或反爬。

## 失效与冲突

- 链接失效：标记 `已失效`，尝试寻找同一机构的替代链接，保留旧记录。
- 数据过期：写明年份，不把旧数据写成当前事实。
- 来源冲突：并列保留差异，说明口径、样本和时间原因。
- 无联网：明确记录证据缺口，不假装已检索。
- 用户提供来源：先用相同规则核验，再进入项目来源索引。
